# Portfolio Project

Full-stack personal portfolio platform with a custom CMS.

## Project Structure

- `portfolio-frontend` — public React/Vite portfolio
- `portfolio-cms` — React/Vite admin CMS
- `portfolio-backend` — Node.js/Express REST API and PostgreSQL integration

CMS: http://localhost:5174
